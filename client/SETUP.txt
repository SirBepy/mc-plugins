SIRBEPY'S FRIENDS SERVER - PLAYER SETUP

                (backup if that doesn't work: eu-de-p59-a6-cg.kineticpanel.net:25566)

No port needed for sirbepy.mcserver.host. The backup address does need the ":25566".


1. JOINING (JAVA, NO MODS NEEDED)
---------------------------------
Plain vanilla Minecraft works. Mods are optional.

1. Open the Minecraft Launcher and make sure it starts version 26.3
   ("Latest release" is fine while 26.3 is the newest; if a newer version is out,
   go to Installations > New installation > pick 26.3).
2. Play > Multiplayer > Add Server.
3. Server Address: sirbepy.mcserver.host
4. Done > double-click the server.

The server does NOT send you a resource pack, so you won't get a "download resource pack?"
prompt. It does have 200+ new foods that need textures on your side: see section 3.


2. OPTIONAL: PROXIMITY VOICE CHAT
---------------------------------
The server runs Simple Voice Chat: you hear people near you, quieter the further away they are.
It's optional. If you don't install the mod, the game works normally, you just won't hear
voice and nobody hears you.

You need the client mod "Simple Voice Chat" version 2.6.24 for Minecraft 26.3 (the server
runs 2.6.24). Pick ONE way to install it:

  A) EASIEST: the modpack file (one click, also includes Sodium for more FPS and the
     food/dungeon textures from section 3)
     1. Install the Modrinth App (https://modrinth.com/app) or Prism Launcher
        (https://prismlauncher.org). Both are free.
     2. Get the file "Los-Pollos-MineHermanos-26.3.mrpack" from Joe.
     3. Modrinth App: click "+" (Create instance) > "From file" > pick the .mrpack.
        Prism Launcher: Add Instance > Import > pick the .mrpack.
     4. Sign in with your Microsoft account in the launcher, then launch the new instance.
     It installs Fabric 26.3 + Fabric API + Simple Voice Chat + Sodium + Iris (shaders,
     off by default, see section 4) + LambDynamicLights (held-light items glow, see
     section 4) + the Reg's More Foods and Dungeons and Taverns textures + a set of
     optional quality-of-life mods (see section 5) for you. Nothing else to set up.
     (The .mrpack format has no slot for a pack icon, so your launcher will show a
     generic icon for this instance - that's expected, not a broken install.)

  B) MANUAL with Fabric (the normal Minecraft Launcher)
     1. Download the Fabric installer from https://fabricmc.net/use/installer/ and run it.
        Choose Minecraft version 26.3, click Install.
     2. Download these files (click the "Download" button on each page):
        - Fabric API 0.161.0+26.3:
          https://modrinth.com/mod/fabric-api/version/bNnaTiuM
        - Simple Voice Chat fabric-2.6.24+26.3:
          https://modrinth.com/plugin/simple-voice-chat/version/OLnMVWXy
        - Sodium 0.9.2 (optional, more FPS):
          https://modrinth.com/mod/sodium/version/bAZQdGpg
        - Reg's More Foods 1.5.2+26.3+mod (food textures, recommended):
          https://modrinth.com/datapack/reg-more-foods/version/ebuLruaV
        - Dungeons and Taverns 6.0.2 Fabric (dungeon key textures, optional, 42 MB):
          https://modrinth.com/datapack/dungeons-and-taverns/version/WilF7nqU
        With the last two in your mods folder you can skip section 3.
     3. Put the .jar files into your mods folder:
        Windows: press Win+R, type %appdata%\.minecraft\mods and press Enter
                 (create the "mods" folder if it doesn't exist).
        Mac:     ~/Library/Application Support/minecraft/mods
     4. In the Minecraft Launcher, pick the "fabric-loader-26.3" installation and Play.

  C) NEOFORGE instead of Fabric (only if you already use NeoForge: its 26.3 version is
     still a beta, so Fabric is recommended)
     Install NeoForge for 26.3 (https://neoforged.net), then put
     Simple Voice Chat neoforge-2.6.24+26.3 in the mods folder:
     https://modrinth.com/plugin/simple-voice-chat/versions?g=26.3&l=neoforge
     (NeoForge does not need Fabric API.) For the food textures, use section 3.

Using voice chat in-game:
- Press V to open the voice chat menu. The first time, it walks you through setup and asks
  you to choose:
    * Push to talk: you only talk while holding a key (default: Caps Lock). Best if you
      have background noise or don't want to be heard by accident.
    * Voice activation: your mic turns on when you speak loud enough. Set the threshold
      slider so your normal voice triggers it but keyboard/background noise doesn't.
- The V menu also has: Settings (pick your microphone and speaker, volumes, change
  push to talk vs voice activation later), Mute yourself, Disable voice chat entirely,
  and Groups (talk to friends anywhere on the map, not just nearby).
- All voice keys can be changed in Options > Controls > Key Binds (Voice Chat section).
- A small icon on screen shows your voice status. If it shows as disconnected,
  see Troubleshooting below.
- Windows/Mac may ask for microphone permission for Java the first time: allow it.

Players on Bedrock (phone, console, Windows Bedrock) can't use voice chat.


3. TEXTURES FOR THE NEW FOODS (RECOMMENDED)
-------------------------------------------
The server adds 200+ new foods (Reg's More Foods) and new dungeons with keys (Dungeons and
Taverns). The server can't send you their textures, so without them the new foods show
wrong/placeholder icons. They still work, they just look off.

Already done for you if you used the modpack (option A) or the manual Fabric list (option B).
Otherwise (plain vanilla, NeoForge), add them as resource packs:

1. Food textures (recommended):
   a. Open https://modrinth.com/datapack/reg-more-foods/version/Ts1r8zla and download
      "Reg's More Foods Pack v1.5.2+26.3 (UNZIP ME).zip".
   b. Unzip it. Inside is "Reg's More Foods Resourcepack v1.5.2+26.3.zip": keep THAT one
      zipped, you don't need the rest.
2. Dungeon key textures (optional, 21 MB, only changes how the keys look):
   download "Dungeons and Taverns v6.0.2.zip" from
   https://modrinth.com/datapack/dungeons-and-taverns/version/iqFWpMVO (don't unzip it).
3. In Minecraft: Options > Resource Packs > Open Pack Folder, and drop the zip(s) in.
4. Back in the Resource Packs screen, hover each new pack on the left and click its arrow
   so it moves to the right ("Selected"). Click Done.

Bedrock can't load these, so on Bedrock the new foods look like placeholders.


4. OPTIONAL: SHADERS AND DYNAMIC LIGHTS
----------------------------------------
Already installed if you used the modpack (option A). Both only change your own game,
nothing on the server, and Bedrock can't use either.

Shaders (Iris + Complementary Reimagined): ship OFF by default so everyone's game starts
fast and looks normal. To turn them on:
  - Press "I" in-game to open the shader pack menu, select Complementary Reimagined
    (already picked for you), and enable it there. Or press "K" to instantly toggle
    shaders on/off without opening a menu.
  - If shaders make your game laggy or crash, press "K" to turn them off again, or open
    the "I" menu and disable them. Both keys can be remapped in Options > Controls >
    Key Binds (Iris section).

Dynamic lights (LambDynamicLights): nothing to turn on. Any torch, lantern, or other
light-emitting item you (or another entity) are holding lights up the area around you
automatically.

7. TROUBLESHOOTING
------------------
"Unknown host" / "Can't resolve hostname" with sirbepy.mcserver.host
  Use the backup address eu-de-p59-a6-cg.kineticpanel.net:25566 (with the :25566).

"Can't connect to server" / "Connection refused" / timed out
  Try the backup address above. If both fail, the server may be down or restarting:
  ask Joe.

"You are not white-listed on this server!"
  Joe has turned on a whitelist. Send him your exact Java username (Bedrock: exact
  Xbox gamertag) and wait for his OK.

"Outdated client" / "Outdated server" / "Incompatible version"
  Your game isn't on 26.3. In the launcher, create an installation for 26.3 (section 1),
  or the Fabric 26.3 instance from section 2.

Voice chat icon says disconnected / nobody hears you
  - Make sure you installed Simple Voice Chat 2.6.24 for 26.3 (not an older version).
  - Press V > Settings and check the right microphone is selected, and that you're not
    muted or have voice chat disabled.
  - Voice uses a separate UDP network port on the server (25604). You don't type it
    anywhere, the mod finds it by itself. If it's broken for everyone,
    tell Joe (the server's voice port may be blocked). If it's only you, your network
    (school/work Wi-Fi, some VPNs) may be blocking UDP: try another network.

Game crashes on start with mods
  Make sure every mod file says 26.3 and you picked the Fabric 26.3 installation.
  Don't mix Fabric and NeoForge files in the same mods folder.

New foods have weird/placeholder icons
  You're missing the food textures: see section 3. If you added the resource pack,
  check it's on the "Selected" side in Options > Resource Packs.
